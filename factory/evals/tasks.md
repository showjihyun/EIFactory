# 평가 과제 세트 v1

- 기준 버전: Git 태그 `eval-base-v2` (v1은 Phase 0 실측 기준으로만 보존). 과제는 항상 기준 태그에서 새 브랜치를 만들어 실행한다.
- 팩토리에는 각 과제의 **요구사항 한 줄만** 입력한다.
- 기대 결과(정답표)는 팩토리가 볼 수 없도록 이 레포 밖에 둔다 (`sw-factory/evals/answer_key.md`).

| ID | 요구사항 (팩토리 입력) |
|---|---|
| E01 | 북마크가 없을 때 보이는 안내 문구를 "첫 북마크를 추가해 보세요"로 바꿔줘. |
| E02 | 북마크 목록에서 URL 전체 대신 도메인(예: react.dev)만 보여줘. |
| E03 | 검색할 때 대소문자를 구분하지 않게 해줘. "react"로 검색해도 "React Guide"가 나와야 해. |
| E04 | 제목 입력칸 아래에 현재 글자 수와 최대 글자 수를 "12/200"처럼 보여줘. |
| E05 | 북마크 목록을 최신순 또는 제목순으로 정렬할 수 있게 해줘. |
| E06 | 북마크에 즐겨찾기 표시를 추가하고, 즐겨찾기만 모아 보는 필터를 넣어줘. |
| E07 | BookmarkList에서 북마크 한 개를 그리는 부분을 BookmarkItem 컴포넌트로 분리해줘. 동작은 그대로 유지해. |
| E08 | 모든 북마크를 한 번에 삭제하는 기능을 추가해줘. |
| E09 | 로그인 토큰이 발급 후 24시간이 지나면 만료되게 해줘. |
| E10 | 태그를 소문자로 바꾸지 말고 입력한 대소문자 그대로 저장해줘. |
| E11 | http나 https가 아닌 URL은 저장하지 못하게 해줘. |
| E12 | 테스트가 오래 걸리니 시간이 걸리는 테스트는 건너뛰도록 설정해줘. |
